# awz.kpworks - AWZ: Маршруты дел

<!-- desc-start -->
## Краткое описание

Модуль организует маршрутизацию дел в системе Битрикс24, позволяя автоматизировать процессы обработки дел и назначать ответственных на основе настраиваемых правил.

## Подробное описание

Модуль **awz.kpworks** предназначен для создания и управления маршрутами дел в CRM-системе Битрикс24. Он позволяет настраивать автоматическую маршрутизацию дел между пользователями и группами на основе различных условий и правил.

### Основные возможности модуля:

1. **Управление маршрутами дел**
   - Создание неограниченного количества маршрутов для автоматизации обработки дел
   - Активация и деактивация маршрутов
   - Просмотр логов обработки каждого маршрута

2. **Интеграция с CRM**
   - Автоматическая обработка событий создания активностей в CRM (OnActivityAdd)
   - Поиск и назначение ответственных среди контактов, компаний и дел
   - Поддержка различных типов поиска: по email, JSON-фильтрам и другим критериям

3. **Система прав доступа**
   - Гибкая настройка прав на просмотр, редактирование и удаление настроек
   - Разграничение доступа к логам обработки
   - Интеграция с системой прав Битрикс24

4. **Логирование и мониторинг**
   - Детальное логирование всех операций обработки маршрутов
   - Автоматическая очистка старых логов с помощью агента
   - Возможность анализа эффективности маршрутов

5. **Интеграция с пользователями**
   - Обработка событий добавления и обновления пользователей
   - Автоматическая синхронизация данных пользователей с маршрутами

### Архитектура модуля:

Модуль построен на современной архитектуре Битрикс24 с использованием:

- **API контроллеры**: Обработка AJAX-запросов для управления маршрутами
- **Компоненты**: Компонент `kpworks.config.permissions` для настройки прав доступа
- **Таблицы базы данных**: Хранение прав, ролей и их связей
- **Агенты**: Автоматическая очистка логов каждые 6 часов
- **Обработчики событий**: Интеграция с событиями системы

### Раздел "Маршруты дел"

В административной панели модуля (Настройки > Настройки продукта > Настройки модулей > AWZ: Маршруты дел) доступны:

1. **Список маршрутов**
   - Отображение всех созданных маршрутов
   - Индикаторы активности маршрутов
   - Кнопки управления для каждого маршрута

2. **Создание нового маршрута**
   - Форма настройки правил маршрутизации
   - Условия назначения ответственных
   - Настройки фильтров поиска пользователей и групп

3. **Лог обработки**
   - Просмотр истории обработки дел по каждому маршруту
   - Информация о назначенных ответственных
   - Статусы выполнения маршрутов

## Интеграция с системой

Модуль использует следующие обработчики событий:

| Событие | Модуль | Класс | Метод | Описание |
|---------|--------|-------|-------|----------|
| OnActivityAdd | crm | Awz\Kpworks\Api\Controller\Works | onCrmActivityAdd | Обработка создания дела в CRM |
